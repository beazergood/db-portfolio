# Brand — Posture, Voice, Style

> Brand is *who* the project is. The [design system](./design-system.md) is *how that shows up* visually. This page is starting-frame, not finished doctrine — append over time, refresh when something stops fitting.

## Posture

- Senior contractor, not a junior. Not loud about it.
- Calm surface. No popups, no urgency theatre, no "just one more thing" modals.
- Show, don't tell. Surface project facets rather than write a CV in prose.
- Hand-drawn warmth (waves, pastels) over corporate sleekness.

## Voice

- First-person, but understated.
- British spelling.
- Plain language. No jargon if a normal word will do.
- Self-deprecating without being insecure.
- Doesn't oversell.

## What we are

- A working canvas for one engineer's ideas, kept alive across years.
- A small, considered surface that returning visitors recognise.
- The kind of site that loads instantly on patchy mobile and never asks for cookies.

## What we are not

- **Not naming named clients or employers in copy.** Project work is described by *kind* (clinical portal, real-time video, sports-data platform) — never by *brand*. This is a hard rule, not a guideline.
- Not a blog (yet, maybe ever).
- Not an "about me" page that lists every job ever held.
- Not a CV. The CV lives elsewhere if needed; the canvas does something different.
